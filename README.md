RADD
====

R - Remote Sensing

A - Ancillary

D - Data

D - Downloader

RADD downloads the ancillary datasets that NISAR soil moisture retrieval needs
from Google Earth Engine and writes them, co-registered, to one NetCDF scene
file per area of interest and date range.
